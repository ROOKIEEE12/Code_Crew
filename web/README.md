# CodeCrew web UI

Next.js frontend for the CodeCrew API. See the root README for setup.

```bash
npm install
npm run dev        # http://localhost:3000 (expects the API at NEXT_PUBLIC_API_URL, default http://127.0.0.1:8000)
npm run gen:api    # regenerate src/lib/api-types.ts from the backend OpenAPI schema
```
